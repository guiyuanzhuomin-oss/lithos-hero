# Lithos

A full-screen geology brand hero built with React, TypeScript, Vite, and Tailwind CSS.

Move the cursor across the landscape to reveal a second geological world through a softly eased spotlight mask.

## Live site

[Open Lithos](https://guiyuanzhuomin-oss.github.io/lithos-hero/)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is deployed automatically to GitHub Pages whenever `main` is updated.
